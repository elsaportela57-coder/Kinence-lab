KINENCE-LAB — PACOTE ATUALIZADO
Autor indicado no site: Ibrahim Domingos
URL atual: https://elsaportela57-coder.github.io/Kinence-lab/

O QUE ESTÁ INCLUÍDO
- index.html: página inicial, pesquisa/filtros, painel de indicadores e calculadora.
- style.css e script.js: estilo responsivo e funcionalidades.
- sobre.html, contacto.html, privacidade.html: páginas institucionais.
- artigos/: seis artigos completos em páginas HTML individuais, para melhor leitura e indexação.
- sitemap.xml e robots.txt: apoio à descoberta das páginas pelos motores de busca.

ANTES DE PUBLICAR
1. Abre contacto.html e substitui SUBSTITUIR-PELO-TEU-EMAIL por um email real que controles.
2. Confirma que tens autorização para publicar o nome de autor usado no site e que os textos refletem o teu trabalho editorial. Revê e acrescenta experiência, fontes e referências específicas quando necessário.
3. Confirma a Política de Privacidade à luz dos serviços realmente usados. Se ativares AdSense, Analytics, formulários ou outros serviços, atualiza a política e verifica requisitos de consentimento aplicáveis.
4. Faz upload de TODOS os ficheiros e pastas para a raiz do repositório kinence-lab, mantendo a estrutura de pastas.
5. Depois da publicação, testa no telemóvel a página inicial, todos os links, os seis artigos, a calculadora e o painel económico.
6. Em https://search.google.com/search-console adiciona/verifica a propriedade do site e pede indexação da página inicial. Podes enviar o sitemap em https://elsaportela57-coder.github.io/Kinence-lab/sitemap.xml.

LIMITES IMPORTANTES
- Sitemap e SEO não garantem indexação nem tráfego.
- A API do Banco Mundial fornece dados estatísticos com períodos próprios, não cotações em tempo real.
- GitHub Pages é alojamento estático; não oferece base de dados nem backend para contas.
- Este pacote não garante aprovação no Google AdSense. O Google avalia o site e a conta segundo os seus requisitos e políticas.
- O Google AdSense exige que o requerente tenha 18 anos ou mais. Se o responsável pelo projeto tiver menos de 18 anos, um pai/mãe/tutor pode inscrever-se com a própria Conta Google e será responsável pelos pagamentos, caso aprovado.

PUBLICAR ATUALIZAÇÃO NO GITHUB (ANDROID)
1. Descompacta o ZIP no telemóvel, se possível, ou usa o navegador para abrir o repositório.
2. No repositório https://github.com/elsaportela57-coder/Kinence-lab, escolhe Add file > Upload files.
3. Envia os ficheiros da raiz e a pasta artigos com os seus seis ficheiros. Não envies apenas o ZIP; o GitHub Pages precisa dos ficheiros extraídos.
4. Confirma que index.html, style.css, script.js, sitemap.xml, robots.txt e as três páginas institucionais estão na raiz; os seis artigos ficam em artigos/.
5. Faz Commit changes e espera alguns minutos.
6. Abre o URL público e testa. Se o GitHub móvel dificultar o envio de pastas, carrega primeiro os ficheiros da raiz e depois cria/atualiza os ficheiros em artigos/ individualmente, ou usa a opção de desktop do navegador.
